# Next Word Prediction Using LSTM

## 📌 Overview

This project predicts the **next word in a sentence** using an **LSTM (Long Short-Term Memory)** neural network.

The model learns word sequences from the training text and predicts the most likely next word.

### Example

```text
Input:  I am learning
Output: machine
```

## 🛠️ Technologies

* Python
* TensorFlow / Keras
* NumPy
* NLP
* LSTM

## 🔄 Workflow

```text
Text Data
   ↓
Tokenization
   ↓
Sequence Creation
   ↓
Padding
   ↓
LSTM Model
   ↓
Next Word Prediction
```

## 🧠 Model

The model uses:

* **Embedding Layer** – converts words into vectors
* **LSTM Layer** – learns word sequence patterns
* **Dense + Softmax** – predicts the next word
